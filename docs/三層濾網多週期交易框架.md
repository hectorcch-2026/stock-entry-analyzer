# 三層濾網多週期交易框架

> 理論骨架取自 Alexander Elder《Come Into My Trading Room》（2002）的三重濾網（Triple Screen）與資金管理體系；
> 訂單流工具（Liquidity Sweep、FVG、Footprint、CVD）屬 2002 年後普及的微觀結構方法，本文將其掛載在 Elder 的週期階層上，並在對應位置標明哪些屬 Elder 原義、哪些屬現代延伸。

---

## 0. 為什麼是「三層」而不是「三個指標」

Elder 三重濾網的核心不是「多用幾個工具」，而是**用不同週期回答不同問題**，且**上位週期的結論對下位週期具否決權**。他在書中的原話大意是：只有當潮汐（tide）與波浪（wave）同向時才出手，而碎浪（ripple）只用來挑選精確的進場時機。

這帶來兩個硬性推論，也是本框架的兩條鐵律：

| 鐵律 | 含義 | 違反的後果 |
|---|---|---|
| **上位否決** | 日線沒給出防守區，1H／15M 再漂亮也不做 | 在無結構的隨機區間裡做「假訊號交易」 |
| **下位僅觸發** | 5M 只決定「何時扣扳機」，不得推翻 1H／15M 的結構判斷 | 被 5M 雜訊牽著走，反覆止損 |

Elder 對週期比例另有建議：相鄰兩層約差 **4～6 倍**。本框架為 日線 → 1H（約 5.5～6.5 倍，視市場交易時段）→ 15M（4 倍）→ 5M（3 倍）。**最下層的 3 倍偏窄**，這正是為什麼第三層被嚴格限定為「觸發層」而非「結構層」——它沒有足夠的解析度去定義結構，只適合確認動能。

## 1. 三層速查表

| | 第一層 | 第二層 | 第三層 |
|---|---|---|---|
| **週期** | 日線（Daily） | 1 小時 ＋ 15 分鐘 | 5 分鐘 |
| **回答的問題** | 大資金的核心防守區在哪？ | 價格進入防守區後，是「真跌破」還是「掃損」？ | 現在扣扳機，還是繼續等？ |
| **工具** | VRVP 成交量分佈、Anchored VWAP、斐波那契 OTE | Liquidity Sweep 判定、FVG 確認 | Footprint 足跡圖、CVD |
| **產出** | 一條「防守帶」（含上緣／核心／下緣） | 一個「確認訊號」或「否決」 | 一個「進場時點」＋「止損位」 |
| **出場責任** | 定義失效位（止損的邏輯來源） | 過濾掉假跌破 | 執行止損與減碼 |
| **Elder 對應** | 第一屏（潮汐） | 第二屏（波浪） | 第三屏（碎浪） |

## 2. 第一層：日線 — 界定大資金的核心防守區

### 2.1 三個工具各自回答一個問題

不要把它們當成「三個都要看的指標」，而是**三個獨立的證據來源**。證據彼此獨立，才會出現「共振」的資訊價值。

| 工具 | 它唯一要回答的問題 | 讀法 | 為什麼是它 |
|---|---|---|---|
| **VRVP 成交量分佈** | 市場的**成本共識**在哪？ | POC＝成交最密集價位；VAH／VAL＝涵蓋 70% 量的上下界 | 成交量分佈反映「多數人建倉的成本」，是套牢盤與獲利盤的分界，屬於**靜態結構** |
| **Anchored VWAP** | 某一批**資金自事件以來的平均成本**在哪？ | 錨定於底部起漲日／最大量日／財報日，取該線當前值 | 它把「時間」納入成本計算，能分辨「舊資金的成本」與「新資金的成本」，屬於**動態結構** |
| **斐波那契 OTE** | 回檔的**合理深度**到哪裡為止？ | OTE ＝ 0.618～0.786 回撤區間，是黃金比例的密集帶 | 它不是「預測」，而是**風險校準尺**：告訴你回檔到哪裡仍屬健康、超過哪裡就是趨勢受損 |

> **Elder 的支撐壓力觀**：他在書中反覆強調「別把支撐壓力當成一條精確的線，它們是**區域**」。這正是本框架用「防守**帶**」而非「防守**價**」的理由——三個工具給出的都是帶狀區間，把它們疊起來才是一條有厚度的帶。

### 2.2 三工具如何互相驗證

**驗證的目的不是「三個都指向同一點」，而是排除「結構互相矛盾」的情況。** 依下列順序檢查：

#### 步驟 A：先確認三者是否落在同一區（空間共振）

三者的關鍵價位若集中在某個價格帶內，該帶的厚度就是防守帶。建議以 **日線 ATR 的 0.5 倍**作為「是否屬於同一帶」的容忍度（約當 1.5～2.5% 的價格帶，視標的波動度）。

```
防守帶下緣 = min( VAL, 錨定 VWAP, OTE 下緣 0.786 )
防守帶核心 = POC 與錨定 VWAP 的重疊區（若重疊）
防守帶上緣 = max( VAH, 錨定 VWAP, OTE 上緣 0.618 )
```

#### 步驟 B：再檢查「方向是否一致」（邏輯共振）

| 情境 | 判讀 | 動作 |
|---|---|---|
| 價格在 POC **之上**，且錨定 VWAP **之上**，回檔落在 OTE 區 | ✅ **三者同向**：舊資金與新資金皆獲利，回檔屬健康 | 進入第二層 |
| 價格在 POC 之上但**跌破**錨定 VWAP | ⚠️ **矛盾**：舊資金仍賺、新資金已虧 → 上方有解套賣壓 | 降低倉位，或等回站 VWAP 再論 |
| 價格在 POC 之下但守住錨定 VWAP | ⚠️ **矛盾**：新資金在護盤，但整體成本區已失守 | 只做「搶反彈」級別的倉位，不可重倉 |
| 價格同時在 POC 與 VWAP 之下，且已跌破 VAL | ❌ **結構失效**：防守區已被否決 | 不做多，改等新結構形成 |

#### 步驟 C：標註關鍵價格帶（三條線，不是十條）

只在圖上保留對**決策**有影響的線，其餘全部關閉：

| 標註 | 來源 | 用途 |
|---|---|---|
| **① 防守帶下緣（紅）** | VAL 或 OTE 0.786（取較低者） | 止損的邏輯位置所在 |
| **② 防守帶核心（藍，粗）** | POC 與錨定 VWAP 的重疊區 | 主要掛單／觀察區 |
| **③ 防守帶上緣（灰）** | VAH 或 OTE 0.618（取較高者） | 確認「已回到防守區內」的門檻 |

> **只有帶，沒有線。** 若三者的價位差距超過 1 個 ATR，代表這個標的當下**沒有共識防守區**——這本身就是一個有效結論：**不做**。Elder 的原則在此適用：找不到優勢，就不要交易。

### 2.3 第一層的過濾原則

- **只保留三個工具**。日線上不再加均線、布林、MACD——它們與「成本結構」這個問題無關，只會干擾。
- **VRVP 回看區間固定**（例如 120 根日線 ≈ 半年），不要每次改參數。參數一改，POC 就漂移，你會在事後合理化自己的進場。
- **錨定 VWAP 最多三個錨點**，且必須是「可命名的事件」（底部起漲、最大量日、財報跳空）。說不出事件名稱的錨點沒有意義。
- **斐波那契只取 0.618／0.786**。其他比例（0.236／0.382／0.5）在這個框架裡不參與決策，關掉。

## 3. 第二層：1 小時 ＋ 15 分鐘 — 假跌破與缺口的確認

**進入條件**：價格已進入第一層定義的防守帶（觸及上緣即開始觀察）。

這一層是整條流程的**關鍵閘門**。多數虧損不是「看錯方向」，而是「在防守區裡被掃損後才啟動」。所以第二層存在的唯一目的是：**分辨「跌破」與「掃損」**。

### 3.1 Liquidity Sweep（流動性掃蕩／假跌破）的判定

**原理**：防守帶下緣、前波低點、等低點（equal lows）下方聚集了大量散戶止損單。大資金要建倉，需要這些止損單提供的流動性。因此「跌破後迅速收回」不是意外，而是**刻意製造**的結果。

#### 必要條件（全部成立才計分）

| # | 條件 | 判讀要點 |
|---|---|---|
| 1 | 價格**跌破**一個「有意義的」前低（防守帶下緣／前波低點／等低點） | 隨便一個盤中低點不算 |
| 2 | **≤ 3 根 15M K 線內**收盤價回到該價位之上 | 這是「掃」與「破」的分界：收回太慢＝真的破了 |
| 3 | 跌破那根的**下影線 ≥ 該 K 線全幅的 50%** | 長下影＝被動成交後被主動買盤推回 |
| 4 | 跌破那根**量能放大**，但收回那根量能**縮小** | 放量掃損 + 縮量收回，代表賣壓已被吸收 |
| 5 | 被掃的價位**落在第一層防守帶內** | 掃掉不重要的價位沒有資訊價值 |

#### 加分條件（提高機率，非必要）

- 掃蕩低點恰好落在 **VAL 或 OTE 0.786** 上（工具共振）
- 掃蕩後 15M 出現**看漲吞沒**或**錘子線**
- 掃蕩低點與前一個低點形成 **SFP（Swing Failure Pattern）**：假突破前低後立刻反轉

> **量化門檻建議**：收回幅度至少達跌破幅度的 **1.5 倍**（例如跌破 1.0%，需在 3 根內收回並上行 1.5%），避免把「緩慢磨破」誤判為掃損。

### 3.2 FVG（公允價值缺口）的確認

**原理**：三根 K 線中，第 1 根的高點與第 3 根的低點之間若無成交，代表該價格區間**買賣雙方沒有達成共識**，是一段「真空」。價格回到此處時，通常會快速通過或獲得支撐——所以它適合當**進場區**，不適合當**目標區**。

#### 看漲 FVG 的必要條件

| # | 條件 | 說明 |
|---|---|---|
| 1 | `第1根.高 < 第3根.低` | 三根 K 線的結構性失衡 |
| 2 | 缺口幅度 **≥ 0.25%** 且 **≥ 0.3 × 15M ATR** | 過濾掉雜訊級別的細縫 |
| 3 | 缺口**與第一層防守帶重疊**（或緊鄰，距離 ≤ 0.5 × ATR） | 否則只是隨機缺口 |
| 4 | 價格回測時缺口**仍未被完全回補** | 已封閉的缺口不再是支撐 |
| 5 | 缺口內出現**止跌訊號**（下影線／量縮／收盤拉回） | 這是「進場區」生效的確認 |

#### 兩個工具如何組合（這是最有價值的部分）

| 組合 | 判讀 | 動作 |
|---|---|---|
| **先 Sweep，後 FVG** | 掃掉止損 → 拉升留下缺口 → 回測缺口 | ✅ **最強訊號**：清掃＋失衡同時成立 |
| 先 FVG，被跌破，再 Sweep 收回 | 缺口失效但流動性已被清掃 | ⚠️ 可做，但倉位減半 |
| 只有 Sweep，無 FVG | 結構性反轉，但缺動能證據 | ⚠️ 等第三層補足 |
| 只有 FVG，無 Sweep | 缺口回測，但止損單未被清掃 | ❌ 上方套牢盤仍在，勝率下降 |
| 跌破後 3 根內未收回 | **真跌破** | ❌ 防守區失效，退回第一層重評 |

### 3.3 第二層的過濾原則

- **1H 定結構，15M 定訊號**。1H 用來看「防守帶是否仍有效」（趨勢方向），15M 用來抓 Sweep 與 FVG。不要在 15M 上做趨勢判斷。
- **同時只開兩個圖**。第三個圖（1H、15M、5M 並列）在實際操作中只會讓你反覆切換、錯過進場。建議：1H 與 15M 並排，5M 需要時才開。
- **Sweep 只認第一層的價位**。每天都有幾十個「假跌破」，只有落在防守帶內的那一個才值得等。
- **FVG 最多保留最近 3 個未回補缺口**。圖上鋪滿缺口等於沒有缺口。

## 4. 第三層：5 分鐘 — 訂單流確認後才進場

**進入條件**：第二層已判定為 Liquidity Sweep（或 Sweep + FVG 組合），且結構未失效。

這一層不判斷方向，只回答一件事：**賣壓是否真的被吸收、買盤是否真的在堆疊？** 若答案模糊，就是「不做」——這是最常被忽略、卻最賺錢的決定。

### 4.1 兩個工具的分工

| 工具 | 它顯示什麼 | 什麼時候用 |
|---|---|---|
| **Footprint 足跡圖** | 每個價位的**主動買量 vs 主動賣量**（bid/ask 分佈） | 需要知道「某個價位到底誰在吃貨」時 |
| **CVD（累積成交量差）** | 主動買量 − 主動賣量的**累積走勢** | 需要知道「整體方向性壓力」時 |

兩者是**同一個現象的微觀與宏觀視角**：Footprint 看單一價位的搏鬥，CVD 看整段時間的累積結果。實務上 **CVD 為主、Footprint 為輔**——CVD 一眼看出背離，Footprint 用來確認那個價位確實有大單吸收。

### 4.2 進場條件的三種確認型態

#### 型態 A：賣盤吸收（Absorption）— 逆勢掃損後的主力型態

| # | 條件 |
|---|---|
| 1 | 價格**創出新低**（掃蕩低點），但 **CVD 未創新低**（看漲背離） |
| 2 | Footprint 在該低價位出現**大量成交卻無法推動價格**（同價位反覆成交、賣方主動打但價格不再下移） |
| 3 | 該價位的 **Delta 由負轉正**，或出現連續的 bid absorption |
| 4 | 價格收回掃蕩低點之上，且**回檔不破**該低點 |

→ 這是「賣方力竭」的實證。Elder 所說的「價格與動能背離」，在日線上用 MACD-Histogram 看，在這裡用 CVD 看——**同一個原理，不同解析度**。

#### 型態 B：主動買盤失衡堆疊（Imbalance Stacking）— 順勢突破型態

| # | 條件 |
|---|---|
| 1 | 價格站回防守帶上緣（VAH／OTE 0.618）之上 |
| 2 | Footprint 出現**連續 3 個以上的對角失衡**（ask 側成交量顯著大於 bid 側，且逐格上移） |
| 3 | **CVD 同步走高**（不是價格漲而 CVD 平——那是有買盤但被更大的被動賣壓吸收） |
| 4 | 回測不破失衡起點 |

→ 這是「主動買盤掌控」的實證。注意第 3 點：**價格漲、CVD 不漲 = 假突破**，這是最常見的陷阱。

#### 型態 C：無訊號（No Signal）

CVD 與價格同步、Footprint 無明顯失衡、掃蕩後橫盤。**這是最常見的結果，也是正確的結果。**

> Elder 的立場很清楚：**交易的目的是「做最好的交易」，不是「每天都交易」**。型態 C 出現時，正確動作是關掉圖表、設好警報、離開。

### 4.3 止損的放置：緊貼流動性掃蕩的最低點下方

這是本框架**唯一允許的止損位置**，理由是它對應「結構失效」而非「金額容忍度」：

```
止損 = 流動性掃蕩最低點 − 緩衝
緩衝 = max( 0.5 × 5M ATR, 該標的 2 個 tick, 掃蕩下影線的 10% )
```

**為什麼不放在 FVG 下緣？** 因為 FVG 被回補不代表結構失效（缺口可以補完再漲），但**掃蕩低點被有效跌破代表「掃損」的假設錯誤**——大資金不是來建倉，是真的在出貨。止損必須對應「我原本的判斷錯在哪」，而不是「我願意虧多少」。

**為什麼要加緩衝？** 止損單若精確貼在低點，會成為下一次掃蕩的獵物。緩衝是為了讓自己不成為流動性。

### 4.4 進出場條件總表

| 項目 | 條件 |
|---|---|
| **進場（多）** | 型態 A 或 B 成立 ＋ 價格已收回掃蕩低點之上 |
| **進場方式** | 分兩批：確認訊號出現先建 1/2，回測不破再補 1/2 |
| **止損** | 掃蕩最低點 − 緩衝（見上式），**進場後不移動** |
| **第一目標** | 防守帶核心（POC／錨定 VWAP）—— 到此減半倉 |
| **第二目標** | 防守帶上緣（VAH／OTE 0.618），或前波高點 |
| **移動停損** | 觸及第一目標後，止損上移至成本價（保本） |
| **全出條件** | 5M 出現反向失衡堆疊，或 CVD 背離反轉 |
| **時間停損** | 進場後 **12 根 5M（=1 小時）** 未達第一目標半程 → 減半或平倉 |

> **時間停損**是 Elder 體系裡容易被忽略的一環。他強調「資金的機會成本」：一筆停滯的交易，占用的是另一個更好機會的額度。

## 5. 執行檢查清單（進場前逐項打勾）

### 第一層（日線）
- [ ] 價格在 POC 之上？（在下方 → 只做搶反彈級倉位）
- [ ] 價格在錨定 VWAP 之上？（跌破 → 降倉或不做）
- [ ] 回檔落在 OTE 0.618～0.786 之間？（未到 → 等）
- [ ] 三者價位差距 ≤ 1 ATR？（超過 → **無共識防守區，不做**）
- [ ] 防守帶三條線已標註，其他指標已關閉？

### 第二層（1H／15M）
- [ ] 1H 趨勢仍支持做多（未跌破防守帶下緣）？
- [ ] 是否出現跌破前低、且 ≤ 3 根 15M 內收回？
- [ ] 下影線 ≥ 該 K 線 50%？量能「放量破、縮量收」？
- [ ] 被掃價位落在第一層防守帶內？
- [ ] 是否有未回補的看漲 FVG 與防守帶重疊？
- [ ] 圖上未回補缺口 ≤ 3 個？

### 第三層（5M）
- [ ] CVD 與價格出現背離（型態 A）或同步走高（型態 B）？
- [ ] Footprint 有吸收證據或連續 ≥3 個失衡？
- [ ] **價格漲但 CVD 不漲**的假突破已排除？
- [ ] 止損位已算出（掃蕩低點 − 緩衝），且風險 ≤ 帳戶 2%？
- [ ] 若今日已虧損 6%，是否已停止交易？

**任何一項打不了勾，就是不做。** 這不是保守，這是 Elder 三重濾網的本意：**濾網的作用是減少交易次數、提高單筆品質**。

---

## 6. 資金管理（Elder 體系中最不該被省略的部分）

Elder 的「三個 M」——Mind（心態）、Method（方法）、Money（資金）——中，多數人只練 Method。但前兩層濾網做得再好，資金管理錯了照樣歸零。

| 規則 | 內容 | 為什麼 |
|---|---|---|
| **2% 規則** | 單筆交易最大風險 ≤ 帳戶淨值 2% | 連續 10 次虧損僅損失約 18%，仍能繼續運作 |
| **6% 規則** | 單月累計虧損達 6% → **當月停止交易** | 防止「報復性交易」把回撤擴大 |
| **部位大小公式** | `股數 = (帳戶 × 2%) ÷ (進場價 − 止損價)` | 先算止損距離，再算股數，**順序不可顛倒** |
| **獲利出場** | 第一目標減半倉、移止損至保本 | 把「不確定」轉為「已鎖定的部分獲利」 |

**這對本框架的實際意義**：因為止損緊貼掃蕩低點（距離通常很小），同樣的 2% 風險可以容納**更大**的部位。這是三層濾網的隱含優勢——**精確的止損位置本身就是槓桿**。但反過來說，止損太近容易被雜訊掃掉，所以第 4.3 節的緩衝計算不可省。

## 7. 圖表精簡與訊號過濾：對抗決策癱瘓

Elder 明確警告過指標過載的危險。以下是本框架的具體取捨原則，每一條都對應一個真實會發生的失敗模式。

### 7.1 核心原則：一張圖只回答一個問題

| 圖 | 只回答 | 允許的元素 | **禁止**出現 |
|---|---|---|---|
| 日線 | 防守區在哪 | VRVP、錨定 VWAP、OTE、三條標註線 | 均線、布林、MACD、KD、RSI |
| 1H | 防守帶還有效嗎 | 防守帶三條線、價格 | 所有指標 |
| 15M | 是掃損還是真破 | 防守帶、FVG、前低 | 均線、成交量以外的指標 |
| 5M | 現在扣扳機嗎 | CVD、Footprint | 其餘全部 |

### 7.2 漸進揭露（Progressive Disclosure）

**只在需要時才打開下一層的工具。** 這是本框架最重要的一條抗癱瘓規則：

```
價格未進入防守帶 → 只開日線圖，第二、三層全部關閉
價格進入防守帶   → 開 1H + 15M
Sweep 成立       → 才開 5M + CVD
```

理由：圖表雜亂的真正代價不是「看不清楚」，而是**大腦會被迫在無關資訊中尋找關聯**，於是看到根本不存在的訊號。減少同時呈現的變數，等於減少幻覺。

### 7.3 訊號取捨的優先序

當多個訊號衝突時，依下列順序裁決（上位覆蓋下位）：

| 優先級 | 訊號 | 覆蓋關係 |
|---|---|---|
| 1 | 第一層結構失效（跌破 VAL 且未收回） | **否決一切做多訊號** |
| 2 | 第二層真跌破（3 根內未收回） | 否決第三層 |
| 3 | Sweep + FVG 共振 | 允許進入第三層 |
| 4 | 第三層 CVD 背離／失衡 | 決定扣扳機 |
| 5 | 任何其他訊號 | **忽略** |

### 7.4 具體的「刪減」清單

- **刪掉所有非決策性指標**：MACD、KD、RSI、布林、雲圖——它們與「成本結構」無關。
- **刪掉多餘的缺口**：只留最近 3 個未回補 FVG。
- **刪掉多餘的錨點**：錨定 VWAP 最多 3 個，且須能說出事件名稱。
- **刪掉盤中雜訊**：5M 圖上不要標支撐壓力線（那是日線的工作）。
- **刪掉「可能有用」的資訊**：新聞、財報倒數、分析師評級——它們不改變執行，只增加猶豫。

### 7.5 一個實用的自我檢查

若你發現自己在同一根 K 線內反覆切換三個週期超過兩次，**這就是決策癱瘓的前兆**。此時的正確動作不是「再看一個指標確認」，而是：

> **離開螢幕。若訊號夠好，它不會在 5 分鐘內消失；若它消失了，那本來就不是好訊號。**

## 8. 框架失效的明確情境（何時該停用）

一個負責任的框架必須說明自己何時不適用：

| 情境 | 為什麼失效 | 替代做法 |
|---|---|---|
| **重大事件前（財報、FOMC、CPI）** | 訂單流失真，跳空跨越止損 | 事件前平倉或不做 |
| **流動性極差的標的**（日均量低、價差寬） | Sweep 與 Footprint 訊號被滑價吃掉 | 只做日線級別，降槓桿 |
| **連續單邊趨勢行情** | 防守帶不斷被穿越，回檔極淺（不到 OTE） | 改用突破策略，本框架空手 |
| **盤整區間內反覆掃蕩** | Sweep 訊號過多，且都失敗 | 等區間被有效突破後再啟用 |
| **加密貨幣 24 小時市場** | 無「日線收盤」，日線結構意義弱化 | 改用 4H 取代日線 |

## 9. 與本專案工具的對應

本文的參數與《股票量化分析專業介面》的計算邏輯一致，可直接對照驗證：

| 框架元素 | 應用中的對應 | 備註 |
|---|---|---|
| 成交量分佈 POC／VAH／VAL | `advancedTools` → `vrvp` 模組，`data.poc / vah / val` | Value Area **目標** 70%，40 個價位格，回看 120 根。註：`data.valueAreaPct` 是實際達成值（整格擴張，通常略高於 70，例如 73.1），不是目標值本身 |
| 錨定 VWAP | `avwap` 模組，自動偵測底部起漲／最大量日／放量突破三類錨點 | `data.series[].isPrimary` 標示主錨點 |
| 斐波那契 OTE | `levels.fib`，含 0.618 與 0.786 | 應用已含全部比例，本框架只用 OTE 兩檔 |
| FVG | `fvg` 模組，`data.active[]` 為未回補缺口，含 `lower / upper / fillRatio` | 最小缺口 0.25% |
| 圖表疊加 | 圖表右上「籌碼分佈」「FVG 缺口」開關 | POC／VAH／VAL 為線，FVG 為向右延伸區間帶 |
| 支撐壓力帶（而非線） | `levels.supports / resistances`，由擺動點叢集而成，含 `touches` 次數 | 對應 Elder 的「區域」觀念 |

**框架與應用的分工**：應用提供第一層的**客觀計算**（防守帶在哪）與部分第二層（FVG）；第二層的 Sweep 判定、第三層的 Footprint／CVD 需要即時逐筆成交資料，屬交易執行端（TradingView、富途、專用訂單流平台）的職責。**應用負責「在哪裡」，執行端負責「何時」**——這也是為什麼兩者不可互相取代。

## 10. 理論出處與界線說明

為避免混淆，明確標示各部分的思想來源：

| 內容 | 來源 |
|---|---|
| 三重濾網（潮汐／波浪／碎浪）、上位週期否決下位 | **Elder《Come Into My Trading Room》** 核心方法 |
| 相鄰週期 4～6 倍比例 | Elder 的建議（本文依實際交易時段調整並標註） |
| 支撐壓力是「區域」而非「線」 | Elder 的明確主張 |
| 2% 規則、6% 規則、三個 M（Mind／Method／Money） | **Elder 資金管理體系** |
| 「寧可不做，也不做沒優勢的交易」 | Elder 的決策哲學 |
| 均線／MACD-Histogram 判別衝動與修正 | Elder 原方法（本框架**刻意不用**，因與成本結構問題無關） |
| Liquidity Sweep、FVG、Footprint、CVD、失衡堆疊 | **現代訂單流方法**（2002 年後普及），非 Elder 原著 |
| 「價格與動能背離」的概念對應 | Elder 的背離觀念，本文以 CVD 在 5M 實現 |

**一句話總結**：Elder 給的是「**用哪個週期問哪個問題，以及錯了要怎麼活下來**」；訂單流工具給的是「**在最後一刻如何確認**」。前者是骨架，後者是血肉，缺一不可——但順序不能顛倒。
