## 1. 設計衝突裁決總表

本節只列裁決結論，規格細節見各對應條目。

| 衝突 | 裁決 | 依據 |
|---|---|---|
| **現價線是否佔 B2 的 5 條配額** | **不佔用。** 現價線獨立為 L0 基準線，不計入「3」、不計入「5」 | 它不是技術位，是觀測基準；佔用配額會導致價格每變動一次就重算配額，其他線閃爍不定 |
| **L1 究竟 3 條還是 4 條**（原報告 B1 列 4 項、B2 說 3 條） | **核心 3 條**（進場上緣／下緣／止損）＋**目標另計 ≤2 條**，合計佔滿 5 | 進場與出場分屬兩個決策階段，混算會讓「目標」擠掉「止損」 |
| **雙目標與配額衝突** | 目標①（＝POC）必顯；目標② 在剩餘名額不足時降為 pill 標籤 | 目標①同時是 L2 結構線，一條線滿足兩個角色，可省一個名額 |
| **B4 手機無法容納完整語義** | 三級降級：完整語義 → 縮寫 → 代號；完整說明移至點擊／長按的浮動 Tooltip | 標籤是 canvas 繪製，無法自動換行；強行完整顯示必然互相覆蓋 |

| **Y 軸是否納入技術位** | **不納入**（與現行相反）。僅取近 N 根 K 線高低 ±5% | 現行納入所有技術位，是 K 線被壓成扁平的直接原因 |

### A5. 現價線：定義為 L0 基準線 【代碼重構】
**[前端繪圖／中工時]**

**規格**

| 屬性 | 值 |
|---|---|
| 層級 | **L0 基準線**（新增，見 B1） |
| 渲染優先級 | **最高**：最後繪製，z-order 位於 K 線之上 |
| 視覺權重 | 細實線 1.0px、透明度 0.9、顏色 `#101828`（中性近黑，不與紅綠語義衝突） |
| 右側標記 | 深底白字 pill，內容「現價 342.15」 |
| 配額 | **不計入「3」、不計入「5」** |
| 降級 | **永不被 B2 自動降級機制隱藏**；使用者可透過模式或圖層開關手動關閉 |
| 邊緣箭頭 | **永不觸發**（收盤價必屬近 N 根，必在視口內；見 A6 例外條款） |

**裁決理由（回應 §1 第一項衝突）**

1. **性質不同**：技術位是「歷史成本結構的推論」，現價是「當下觀測值」。前者隨標的改變，後者隨時點改變。
2. **避免配額震盪**：若佔用配額，每當價格穿越某條線，配額重算會導致其他線閃入閃出。
3. **它是座標系原點**：框架的所有判斷（價格在 POC 之上／之下、是否進入 OTE、距防守帶幾 %）都以現價為基準。隱藏它，其餘標註失去參照。

**驗收標準** → AC-04

### A6. Y 軸視口裁切規則 【代碼重構｜新增】
**[前端繪圖／中高工時]**

**規格**

| 項目 | 規則 |
|---|---|
| 取樣範圍 | 僅取**近 N 根 K 線**的最高價與最低價 |
| N 定義 | `N = min(圖表可見根數, 120)`，預設 120 |
| N 的依據 | 與 VRVP 回看 120 根對齊純屬**視覺便利**，兩者無資料依賴，可獨立調整 |
| 縮放 | `lo = minLow − 0.05×(maxHigh−minLow)`；`hi = maxHigh + 0.05×(maxHigh−minLow)` |
| 排除項 | 所有技術位、均線、布林、VP、FVG **一律不再參與 lo/hi 計算** |
| 例外 1 | L0 現價若因資料異常落在範圍外，強制納入 |
| 例外 2 | 若 L1 三條決策線**全部**落在視口外，顯示提示條「決策區在下方 X%」，**不得**為此壓縮視口 |

**為何要改（與現行相反）**
現行程式把支撐、壓力、買入區間、POC／VAH／VAL、FVG 全部納入 lo/hi 計算。只要有一條遠端技術位（例如半年前的低點支撐），K 線就會被壓縮成扁平帶狀，這是「圖表看不懂」的主要成因之一，比配色問題嚴重。

**配套**
超界線的呈現由 B7 定義，兩者必須同批實作，否則會出現「線消失且無提示」。

**驗收標準** → AC-06

### B1. 五級視覺層級（新增 L0 基準線） 【文件修訂】
**[文件修訂／零代碼]**

**規格**

| 層級 | 內容 | 線寬 | 線型 | 透明度 | 標籤 | 配額 |
|---|---|---|---|---|---|---|
| **L0 基準線** | **現價** | 1.0 | 實線 | 0.90 | 必標，右側 pill | **不計入** |
| **L1 決策線** | 進場區上緣、下緣、止損 | 2.0 | 實線 | 1.00 | 必標 | 3 |
| **L1-T 目標線** | 目標①、目標② | 1.6 | 虛線 `[6,3]` | 1.00 | 必標（②可降級） | ≤2（與 L1 共用 5） |
| **L2 結構線** | POC、VAH、VAL | 1.2 | 虛線 `[5,3]` | 1.00 | 有空間才標 | 共用剩餘 |
| **L3 參考線** | 支撐、壓力 | 1.0 | 點線 `[2,4]` | 0.45 | 僅 hover／tooltip | 共用剩餘 |
| **L4 背景** | FVG 填色、VP 柱、MA 曲線 | — | — | ≤0.18 | 無 | 不計 |

**L0 的三項特殊規則（回應原報告缺失）**

1. **最高渲染優先級**：繪製順序為 L4 → L3 → L2 → L1 → K 線 → **L0** → hover。L0 最後繪製，確保不被任何圖層遮蓋。
2. **不計入任何配額**：不計入「3」、不計入「5」、不計入填色「2」。
3. **不可被自動降級**：B2 的降級鏈（L3→L2→L1-T②）不以 L0 為對象。

**為何不用顏色區分層級**
現行 `COLORS.up` 與 `COLORS.resistance` 同為 `#d92b2b`，`COLORS.down` 與 `COLORS.support` 同為 `#0f9d58`——四條不同意義的線只有兩種顏色。且 `buyZone.target` 取 `resistances[0]`，當壓力存在時目標線與壓力線同值同色，等於少一條線。層級改由線寬與線型承載，顏色僅保留漲跌語義。

| **L0** | （原報告未定義） | **獨立，不計入以上任何配額** |

**配額分配優先序**

| 優先 | 線 | 層級 | 超額時處理 |
|---|---|---|---|
| 1 | 進場區下緣 | L1 | 永不降級 |
| 2 | 止損 | L1 | 永不降級 |
| 3 | 進場區上緣 | L1 | 永不降級 |
| 4 | 目標①（＝POC／防守帶核心） | L1-T | 永不降級（一條線滿足兩角色） |
| 5 | 目標② | L1-T | 降為 pill 標籤，不畫線 |
| 6 | POC（若與目標①不同值） | L2 | 併入目標①標籤顯示 |
| 7 | VAH／VAL | L2 | 降為 pill 標籤 |
| 8 | 支撐／壓力 | L3 | 僅 hover |

**典型結果**：下緣、止損、上緣、目標①(POC)、目標②＝**5 條**；VAH／VAL 降為 pill，支撐壓力僅 hover。相對現行 13 條，降幅 62%。

**現行基線（供比對）**

```
支撐3 + 壓力3 + 買區上下2 + 停損1 + 目標1 + POC1 + VAH1 + VAL1 = 13 條
```

**降級鏈的執行時機**
必須在**資料變更時**計算一次並快取，不得在每次重繪時重算——否則價格變動會導致線條閃爍。
